Архитектура

Система состоит из трех Микросервисов:

GateWay (порт 8080) — принимает все запросы от фронтенда и перенаправляет их на нужный сервис.

PaymentsService (порт 8081) — отвечает за счета пользователей, баланс и списание средств.

OrdersService (порт 8082) — создает заказы и хранит их историю.

RabbitMQ — используется для передачи сообщений об оплате между сервисами заказов и платежей.

PostgreSQL — два отдельных контейнера БД.

Как запустить

1. Сборка приложений Для сборки используется docker-compose:
```
Bash
docker-compose up -d --build
```
Флаг -d запустит контейнеры в фоновом режиме.

2. Проверка После запуска фронтенд доступен по адресу: ```http://localhost:8080```.
3. Панель управления RabbitMQ: ```http://localhost:15672``` (логин и пароль по умолчанию: guest).

Порты для Swagger:

```http://localhost:8080/swagger-ui/index.html``` - для тестирования gateway

```http://localhost:8081/swagger-ui/index.html``` - для тестирования PaymentsService

```http://localhost:8082/swagger-ui/index.html``` - для тестирования OrdersService

Порты и подключение к БД

Если нужно проверить данные в таблицах, порты проброшены следующим образом:

База платежей: localhost:5433 (логин: user, пароль: password)

База заказов: localhost:5431 (логин: user, пароль: password)
